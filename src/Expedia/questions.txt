- [LC 1235] https://leetcode.com/problems/maximum-profit-in-job-scheduling/
	Given an array of stock trading logs: [buy_time, sell_time, profit]

	Given the logs, I can choose trades which don't overlap. For example
	
	0: [1, 3, 20]
	1: [2, 4, 10]
	2: [3, 5, 10]
	0 and 2 are not overlapping. sell_time and buy_time can be equal because as soon as sell on day 3, 
	I can buy a stock on day 3 again. 0 and 1 are definitely overlapping.
	So you need to choose non-overlapping trades that sum up a maximum profit.


	N.B. This is similar to LC-1235. It would become different only if the problem adds extra constraints like:

	cooldown days
	transaction limits
	multiple simultaneous holdings
	mandatory ordering rules
